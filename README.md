# SENTINEL AI CCTV

An AI-powered intelligent CCTV monitoring, detection, tracking and alert management system.

## 🎯 Objective

SENTINEL AI is designed to provide an intelligent CCTV monitoring platform that can analyze video feeds, detect objects and events, track entities across cameras, and generate actionable alerts through a centralized dashboard.

## 🚀 Core Features

- AI-based CCTV video analysis
- Real-time object detection
- Object tracking
- Vehicle detection
- Number plate recognition
- Multi-camera monitoring
- Event detection
- Intelligent alert generation
- Camera status monitoring
- Vehicle/event search
- Analytics dashboard
- Role-based authentication
- Centralized monitoring dashboard

## 🏗️ Architecture
